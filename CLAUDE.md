# x-lorenzofl0w — агенты для аккаунта @lorenzofl0w

Аккаунт: **@lorenzofl0w** (Lorenzo). Истории о деньгах за известными именами: наследства, завещания,
разводы, сделки, налоги. Около 940 подписчиков (октябрь 2026). Аудитория в основном из США, посты пишем
на английском, если в `brief.md` не сказано иначе.

Хозяйка аккаунта — **Полина**. Публикует всегда она сама, руками. Этот репозиторий готовит черновики,
разбирает цифры и учится на результатах и на её правках.

Соседний репозиторий `../x-markelling` — другой аккаунт с другим голосом. **Его файлы не читать.**

## Жёсткие правила

1. Ничего не публиковать и не отвечать в X. Никаких действий в аккаунте.
2. `brief.md` важнее `playbook.md`. `brief.md` меняет только Полина; агенты предлагают правки текстом
   в описании pull request (через /coach).
3. `playbook.md` меняет только тренер (агент coach через /coach) — в отдельной ветке `coach/YYYY-Www`
   и через pull request. Мержит только Полина.
4. Запись в Twitter Factory (`record_profile_analytics`, `record_post_metrics`) — только после того,
   как Полина подтвердила цифры в этом диалоге. В режиме без человека — никогда.
5. Факты, цифры, даты и цитаты в постах помечать «проверить: <источник>».
6. Правило без числа постов и цифр — гипотеза, а не правило.
7. В режиме без человека (`claude -p`) не задавать вопросов. Чего не хватает — писать в раздел
   «Нужно от Полины» итогового файла скилла и идти дальше.

Каждый скилл в конце коммитит свои файлы (тренер — в своей ветке). Ничего, кроме своих файлов, в коммит
не добавлять. В `main` не мержить, `push --force` не делать.

## Время

Везде Europe/Warsaw. Для этого аккаунта рядом указывать ET (America/New_York): аудитория в США.
Дату, неделю и ET брать из `node scripts/now.mjs` (без аргумента — сейчас; с ISO-временем — пересчёт
момента). Разница Варшава–ET меняется: 6 ч обычно, 5 ч с 25.10 по 01.11.2026 (Европа и США переводят
часы в разные дни). Не считать в уме.

## Агенты (`.claude/agents/`)

| Агент | Что делает |
|---|---|
| `author` | пишет 2–3 варианта поста на тему в голосе аккаунта, с применением текущего эксперимента |
| `critic` | оценивает варианты по чеклисту из 10 баллов; видит только тексты, `brief.md`, `playbook.md` |

| `competitor` | разбирает чужие посты ниши с большими просмотрами: хук, структура, триггер, формат; ведёт библиотеку паттернов `competitors/patterns.md` |

## Twitter Factory (MCP)

Сервис мониторинга X Полины. В репозиторий сервиса ничего не писать.
Ниша аккаунта: **finance** («Finance»). В той же нише лежит и @markelling_, поэтому материал ниши общий;
отбирать темы только под `brief.md` этого аккаунта.

**twitter-factory** — единственный MCP-сервер (`TF_OWN_ACCOUNT=lorenzofl0w`, `TF_WORKSPACE=finance`). Инструменты читают базу напрямую:

| Инструмент | Зачем |
|---|---|
| `my_posts` | свои посты с метриками и историей замеров (текст до 500 знаков) |
| `get_post` | один пост целиком: полный текст, метрики, LLM-разбор |
| `search_posts` | поиск по тексту/автору/периоду — проверка на повтор своих тем |
| `top_posts` | лучшие посты ниши за период (`workspace: "finance"`) |
| `top_replies` | популярные ответы |
| `hooks` | библиотека хуков ниши с шаблонами |
| `niche_people` | о ком пишут в нише |
| `accounts` | мониторимые аккаунты |
| `weekly_digest` | недельная сводка — **только с `save: false`**, иначе пишет файл в репозиторий сервиса |
| `health` | жива ли база и сбор |

Инструменты через API бэкенда (нужен ADMIN_TOKEN; на 25.10.2026 в сессии не были подключены, проверять наличие через `health` и список инструментов):

| Инструмент | Зачем |
|---|---|
| `rising_posts` | свежие посты, которые растут быстрее обычного |
| `pushed_topics` | темы, которые алгоритм толкает у маленьких аккаунтов |
| `what_works` | сочетания приёмов и триггеров в вирусных постах ниши |
| `posting_times` | карта «день × час»; `own: true` — свой аккаунт; `tz: "Europe/Warsaw"`. Ответ большой и обрезается на 40 тыс. знаков — бери `range: "1m"` |
| `own_stats` | дневные срезы аккаунта; показы/визиты/подписки — только внесённые вручную, пусто = «не вносили» |
| `own_posts` | свои посты с публичными метриками |
| `own_published` | черновики студии сервиса с цифрами X Analytics (id для `record_post_metrics`) |
| `latest_report` | последний отчёт сервиса по аккаунту |
| `record_profile_analytics`, `record_post_metrics` | запись цифр X Analytics — только после подтверждения Полины |

Если MCP не отвечает (бэкенд выключен, нет переменных) — работать с тем, что есть, и записать
в «Нужно от Полины», какой инструмент упал и с какой ошибкой.

Переменные окружения: `TF_REPO` (путь к twitter-factory), `TF_ADMIN_TOKEN`, при необходимости
`TF_MONGODB_URI`, `TF_API_URL`. Токен в git не попадает.

## Определения

- **ER** = (лайки + ответы + репосты + цитаты) / просмотры. Закладки — отдельной колонкой
  (бывают `null` = «не знаем», не ноль).
- **Медиана**, не среднее: один вирусный пост ломает среднее.
- Посты моложе 48 часов не оцениваются.
- id черновика: `D-YYYYMMDD-N` (дата черновика по Варшаве, N — номер поста в файле дня).
