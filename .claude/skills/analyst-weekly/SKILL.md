# /analyst-weekly — разбор недели

Работает и интерактивно, и через `claude -p`. **Вопросов не задавать**: чего не хватает — в раздел
«Нужно от Полины» итогового файла. Цифры считает агент `analyst` (медианы, посты < 48 ч не оцениваем).

## 1. Какая неделя

- `node scripts/now.mjs` → `previousIsoWeek`, `previousWeek` (пн–вс по Варшаве). Разбираем прошлую
  неделю целиком. Можно передать аргументом другую неделю: `2026-W44`.
- Итоговый файл: `analytics/<previousIsoWeek>.md`. Если уже есть (например, туда писал /screenshots) —
  обновить таблицу и разделы, не затирая колонки X Analytics, которые уже заполнены.

## 2. Данные

- `latest_report`. Отчёт сервиса строится по понедельникам в 9:00. Если его период не покрывает
  разбираемую неделю — записать в «Нужно от Полины» («отчёт сервиса за <неделя> не построен») и считать
  по `my_posts`.
- `my_posts` (days: 14, limit: 100) — оставить посты разбираемой недели.
- `own_stats` (days: 7) — подписчики по дням; показы/визиты/подписки только если вносили.
- `posting_times` (own: true, tz: "Europe/Warsaw", range: "1m").
- `own_published` (awaiting: true) — посты студии, по которым ждут цифры X Analytics.
- `drafts/` и `edits.md` — id черновика для каждого поста.
- `experiments.md` — активный эксперимент и правило разметки вариантов.

## 4. Эксперимент

В `experiments.md`, в активном эксперименте, обновить строку «Промежуточные цифры» (неделя, n и медианы
по вариантам). Итог не подводить — это делает /coach.

## 4a. Эталоны

В `data/my-posts.md` проверить, не вошёл ли в топ-10 по просмотрам или в «Худшие 10» пост старше 48 часов
(оригиналы и цитаты, без ответов). Если вошёл, обновить таблицу и карточку по образцу соседних (полный текст —
`get_post`; хук, мост к видео, концовка, время Варшава/ET из `scripts/now.mjs`), поправить блок «Что повторяется»
и дату снимка. Метрики постов старше 48 часов не пересчитывать. Подписки на 1000 показов обновлять из
`data/post-analytics.md` и `analytics/x-analytics-log-2026-10.md`. В `data/phrase-log.md` добавить конструкции, которые
за 14 дней встретились в 3 постах. Журнал ответов в `docs/replies-policy.md` пополнять из `my_posts` с `include_replies: true`. Правки `playbook.md` не делать — это coach.
