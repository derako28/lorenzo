# /scout — разведка тем

Работает и интерактивно, и через `claude -p`. **Вопросов не задавать**: чего не хватает — в раздел
«Нужно от Полины» отчёта, и идти дальше. Аргумент `no-commit` — всё сделать, но не коммитить.
Рекомендуемое время по расписанию — раз в день до `/daily` (например 6:00 по Варшаве). Расписание ставит Полина.

## 1. Состояние

- `node scripts/now.mjs` → дата, время по Варшаве и ET.
- Прочитать `brief.md`, `topics/pool.md` (счётчик типов, что уже в пуле), `data/my-posts.md`.
- Если пользователь передал тип — искать только его; иначе ротация по наименьшему счётчику.

## 2. Вызвать агента `scout`

Передать: дату, путь `topics/pool.md`, тип (если задан), лимит — до 10 новых кандидатов. Агент пополняет таблицу
пула и возвращает отчёт. Повторно проверить свежесть тех записей пула со статусом «новая» или «проверена», у которых
дата проверки старше 7 дней: статус «занята нишей» снять, если за последние 30 дней в нише про героя пусто.

## 2a. Проверка видео через расширение Chrome (обязательна)

Видео нужно всегда. Для каждого кандидата со зацепкой, добавленного в этом запуске, и для записей со статусом `новая`:
- Загрузить инструменты расширения (`mcp__claude-in-chrome__*`) одним ToolSearch, открыть новую вкладку, в конце закрыть.
- Искать на YouTube с сортировкой по просмотрам (`&sp=CAM%253D`), запросы: имя героя + interview / speaks / talks about money.
- Нужен ролик, где **герой сам говорит** о теме поста, на английском, от 100 тыс. просмотров, без возрастного ограничения. Каналы-источники — в `topics/video-sources.md`: сначала ищи там.
  Проверить: просмотры и длительность (`ytInitialPlayerResponse.videoDetails`), транскрипт или таймкоды, плотность и споры в
  комментариях (хотя бы 1–2 комментария на 1000 просмотров).
- Подходит — записать в колонку «Видео» ссылку, просмотры, длительность; статус `проверена <дата>`.
  Не нашёл или не проходит — статус `нет видео <дата>` и строка, что искал. Такие записи не берут `/daily` и `/lorenzo-x-post`.
- Расширение не отвечает — записи остаются `новая`, в «Нужно от Полины» записать причину. Не подтверждать видео по названию.

## 3. Счётчик типов

Обновить в `topics/pool.md` колонку «В пуле» по числу записей каждого типа со статусом «новая» / «проверена».

## 4. Коммит

Если не `no-commit`:

```
git add topics/pool.md
git commit -m "scout: пул тем <date>"
```

Только этот файл. Не пушить. В конце напечатать сводку: добавлено, лучшие 3, занято нишей, «Нужно от Полины».
